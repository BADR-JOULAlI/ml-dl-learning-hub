# Feuille de route d’apprentissage

## Rythme

Le chemin central tient en quatorze semaines : 2–4 heures de cours guidé et 2–4 heures de pratique par semaine. Pour un atelier de club, prévoir une séance de notions, une séance de notebook/exercices et une courte revue de projet.

## Jalons

1. **Décrire les données** : type des variables, unités, valeurs manquantes et cible.
2. **Construire une baseline** : une prédiction naïve et un modèle simple.
3. **Évaluer honnêtement** : séparation adaptée, métrique justifiée, erreurs inspectées.
4. **Améliorer avec une hypothèse** : une modification à la fois et comparaison équitable.
5. **Rendre reproductible** : graine, versions, transformations entraînées sur train seulement.
6. **Partager** : README, limites, résultat, commande d’exécution.

## Parcours alternatifs

- **Débutant** : 00 → 01 → 02 → 03 → 04 → 05, puis projet prix.
- **Data analyst** : 01 → 03 → 04 → 05, puis retour aux éléments de maths nécessaires.
- **Deep Learning** : 00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 ou 09.
- **ML engineering** : 00 → 01 → 03 → 04 → 05 → 10 → 11 → 12.

Un module avancé dépend de concepts réellement introduits ; les passer sans expérience de validation peut mener à des résultats trompeurs.
