# Prérequis

## Python

Avant le module 01, savoir affecter une variable, écrire un `if`, parcourir une liste, définir une fonction et importer un module. Une compréhension préalable des classes est utile, mais pas nécessaire pour démarrer.

## Mathématiques

Les notions sont introduites dans le module 02 avec des nombres simples et des visualisations. Pour aller plus vite : vecteurs, pentes, fonctions, dérivée d’une fonction polynomiale, moyenne et probabilités élémentaires.

## Outils

Savoir ouvrir un terminal, installer Python, créer un dossier et éditer un fichier texte. Git est présenté en module 00 ; on peut commencer les premiers notebooks avant d’être à l’aise avec les branches.

## Auto-évaluation

1. Pouvez-vous écrire une fonction prenant une liste et retournant sa moyenne ?
2. Pouvez-vous expliquer pourquoi une ligne de données est une observation et une colonne une variable ?
3. Pouvez-vous lire une erreur Python et retrouver la cellule qui l’a produite ?

Si l’une des réponses est non, révisez Python de base pendant quelques heures puis reprenez le cours. Le cours ne suppose pas d’expérience préalable avec scikit-learn ou PyTorch.
