# Module 10 — Projets appliqués

**Niveau :** adapté au projet · **Durée :** 8–12 h · **Prérequis :** modules 03–05 pour tabulaire ; module 07 pour vision ; module 09 pour NLP.

Chaque projet impose : question et unité d’observation, provenance/licence des données, EDA, split, baseline, pipeline, amélioration motivée, métriques adaptées, analyse d’erreurs, limites et prochaines expériences.

| Projet | Livrable | Statut |
|---|---|---|
| [Prix immobiliers](../../projects/house-price-prediction/README.md) | Comparaison moyenne vs forêt sur jeu synthétique reproductible. | Script et test exécutables. |
| [Attrition](../../projects/customer-churn/README.md) | Classification de données synthétiques et métriques déséquilibrées. | Brief et générateur de données inclus. |
| [Images](../../projects/image-classification/README.md) | Baseline et CNN sur chiffres inclus dans scikit-learn. | Parcours spécifié ; entraînement complet reste à écrire. |
| [Sentiment](../../projects/sentiment-analysis/README.md) | Pipeline TF-IDF, évaluation et erreurs lexicales. | Brief et corpus pédagogique à petite échelle. |

Les jeux synthétiques permettent de tester les étapes, mais n’autorisent aucune conclusion sur des ménages ou abonnés réels. Documenter explicitement cette limite.
